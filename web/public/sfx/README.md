# Sound effect clips

Drop an OGG or MP3 here named after a sound and it replaces the synthesized version of that sound (see `src/lib/sfx.ts`).
Names: `card`, `deal`, `click`, `tile`, `ocean`, `chime`, `claim`, `coin`, `turn`, `bad`, `fanfare`.

Keep clips short (under a second, the fanfare a bit longer) with no leading silence, so they feel instant.
